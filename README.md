# AUM — Among Us Modder

Менеджер модов для Among Us с автоматической установкой, обновлением и кастомизацией.

---
### 1. AUM

**Функции:**
- Установка и удаление модов для Among Us
- Поддержка Steam и Epic Games версий
- Система активации через ключи (PRO функции)
- Кастомизация интерфейса (цвета, темы)
- Профиль пользователя с реферальной системой
- Облачная синхронизация настроек
- Discord Rich Presence
- Автоматическое обновление модов
- Мультиязычность (русский, английский)
- Режим стримера (скрытие ключа)

### 2. Telegram бот 

**Функции:**
- Генерация и управление ключами активации
- Проверка активации ключей
- Админ-панель для управления пользователями
- Облачная синхронизация настроек
- Проверка обновлений модов
- API сервер для приложения

### 3. Сайт

Статический сайт для информации о проекте и скачивания установщика.

**Страницы:**
- index.html — Главная страница с кнопкой скачивания
- social.html — Социальные сети
- terms.html — Условия использования
- privacy.html — Политика приватности
